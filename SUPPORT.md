# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Before
opening an issue, check the current release notes and existing issues.

Include the scrcpy-tui version, Linux distribution and architecture, terminal,
adb and scrcpy versions, exact command or keys, expected result and sanitized
diagnostics. Remove device serials, private addresses and credentials.

The project is maintained on a best-effort basis and offers no response-time
SLA. Security reports follow the private process in [SECURITY.md](SECURITY.md).
