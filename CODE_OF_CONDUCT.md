# Code of conduct

We want participation in scrcpy-tui to be respectful, constructive and safe.
Contributors must communicate without harassment, personal attacks,
discrimination, intimidation or publication of another person's private data.

Maintainers may edit or remove contributions and restrict participation when
behavior harms the project or its community. Enforcement decisions should be
proportionate, documented privately and avoid exposing reporters.

Report conduct concerns privately to the maintainers through the organization’s
GitHub contact channels. Report software vulnerabilities through the private
process in [SECURITY.md](SECURITY.md), not through a public issue.

This policy applies in repository discussions, issues, pull requests and other
spaces where someone represents the project.
